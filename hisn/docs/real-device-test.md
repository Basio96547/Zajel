# حصن — بروتوكول اختبار الجهاز الحقيقي (نفّذه على هاتفك)

الهدف: كشف ما لا يظهر على المحاكي — تأخير التشغيل الخلفي (Android 12+)، وضع Doze،
اختلاف `QUERY_ALL_PACKAGES` بين الإصدارات، وخدمات الوصول الحقيقية.

## التحضير
```bash
# ثبّت البناء الحالي
./gradlew :hisn:assembleDebug
adb install -r hisn/build/outputs/apk/debug/hisn-debug.apk
adb shell pm grant com.hisn.app android.permission.POST_NOTIFICATIONS

# راقب سجلّ حصن في نافذة منفصلة طوال الاختبار
adb logcat -s Hisn:* AndroidRuntime:E
```
سجّل: **موديل الجهاز + إصدار أندرويد + هل مروت؟**

## الفحوصات (بالترتيب)

| # | الخطوة (على الهاتف / adb) | المتوقع | بلّغني |
|---|---|---|---|
| 1 | افتح التطبيق، انتظر الفحص الأول | درجة أساسية | الدرجة + هل تطابق حالة جهازك؟ |
| 2 | ثبّت تطبيقاً وهمياً ثم امنحه Accessibility + الكاميرا + الميكروفون يدوياً من الإعدادات | إشعار **فوري** (PackageChangeReceiver ثم عند منح الوصول عند الفحص التالي) | وصل؟ خلال كم؟ هل السبب واضح ("خدمات إمكانية الوصول: من سليم إلى خطر")؟ |
| 3 | `adb shell settings put global adb_enabled 1` (أو فعّل تصحيح USB من الإعدادات)، ثم «فحص الآن» | الدرجة −8 | ظهر التغيّر؟ |
| 4 | ألغِ قفل الشاشة من الإعدادات، ثم «فحص الآن» | الدرجة −25 | الدقة صحيحة؟ |
| 5 | «فحص الآن» مرّة أخرى بلا أي تغيير | **لا إشعار** | هل صمت بأمانة (change=null)؟ راقب السجلّ: `worker/scan ... change=null` |
| 6 | اترك الجهاز ٢٤ ساعة (بطارية عادية، Doze فعّال) | WorkManager يُطلق فحصاً | وصل إشعار إن تغيّر شيء؟ أم ابتلعه Doze؟ |
| 7 | «تصدير السجلّ» | ملف JSON | افتح الملف — السلسلة كاملة؟ |
| 8 | انقل الـ JSON لجهاز/محاكي آخر، افتح حصن ← أيقونة التحقّق ← اختر الملف | «السلسلة سليمة» + «ختم الجهاز غير مؤكَّد هنا» | ظهرا كلاهما؟ |
| 9 | عدّل رقماً واحداً في الـ JSON (مثلاً score)، استورده | «السلسلة مكسورة عند الإدخال رقم N» | كشف الكسر عند الفهرس الصحيح؟ |
| 10 | كرّر 1–5 على Android 10 و12 و14 إن توفّرت | لا تعطّل | هل `QUERY_ALL_PACKAGES` يعدّد التطبيقات على كل إصدار؟ فرق في التأخير؟ |

## ما تبحث عنه (وليس فقط "يعمل")
- **التأخير:** كم بين الحدث والإشعار؟ (Android 12+ قد يؤخّر البثّ الخلفي)
- **البطارية/Doze:** هل فحص الـ 24 ساعة أُطلق فعلاً؟ (WorkManager يحترم Doze — قد يتأخر لنافذة الصيانة)
- **الدقة:** هل الدرجة منطقية لجهازك الفعلي؟
- **الاستقرار:** أي سطر `E AndroidRuntime` أو `FATAL` في Logcat؟ انسخه.
